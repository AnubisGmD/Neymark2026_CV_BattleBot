# ⚔️ Neymark2026_CV_BattleBot 🤖

![BattleBot CV Diagram](battlebot_cv_diagram.png)

**Умный боевой робот на базе компьютерного зрения (OpenCV), способный в реальном времени отслеживать ArUco-маркеры, плавно маневрировать по полю и охотиться на роботов-соперников.**

Проект включает в себя полноценную систему автономного управления (автопилот), неблокирующий привод оружия (сервопривод) и интерактивный веб-пульт управления для телефонов и ПК.

## 🚀 Основные возможности

* **⚔️ Режим охоты (Hunt Mode):** Робот автоматически сканирует поле на наличие ArUco-маркеров врагов (`ENEMY_MARKER_IDS`). При обнаружении соперника он бросает мирное прохождение контрольных точек, разгоняется до максимальной скорости (`ATTACK_SPEED_MM_S = 400`) и идет на непрерывный таран, раскручивая оружие (ускоренное качание сервопривода).
* **🏎️ Плавное подруливание (P-регулятор угла):** Вместо резких разворотов на месте робот использует пропорциональный регулятор для плавного захода на виражи по дуге на полной скорости. Разворот на месте выполняется только при критических углах ($> 45^\circ$).
* **📱 Мобильный веб-интерфейс (Flask):** Легковесный пульт управления, доступный с любого устройства в сети (телефона/ПК). Позволяет:
  * Включать/выключать автопилот.
  * Активировать/деактивировать **Режим Охоты**.
  * Задавать цель вручную (кликом по кадру камеры).
  * Тестировать манипулятор/сервопривод.
  * Просматривать телеметрию (команда, координаты, посещенные точки) и опционально выводить видеопоток.
* **🎯 Автономный обход точек:** Робот находит ближайшие не посещенные маркеры и последовательно обходит их. При достижении цели он останавливается на 0.8 сек для быстрого сканирования оружия, а затем едет дальше.

## 🛠️ Технологический стек

* **Язык:** Python 3.9+
* **Компьютерное зрение:** OpenCV (модуль `aruco`)

* **Сеть:** Мультипоточность (`threading`), TCP сокеты для управления контроллером робота.

## 📟 Прошивка ESP32-C3

В репозитории доступна финальная прошивка для модуля управления роботом в файле [esp32.ino](esp32.ino).
Прошивка решает следующие транспортные задачи:
* Создание Wi-Fi точки доступа (`NEYMARK_01` / `neymark123`).
* Поднятие DHCP-сервера с IP-адресом робота `192.168.4.1`.
* Запуск TCP-сервера на порту `8888` для приема управляющих команд от автопилота на Mac.
* Трансляция TCP-команд в аппаратный порт UART (скорость 38400 бод) для непосредственного исполнения на плате Arduino.
* Хостинг статусной веб-страницы на порту `80` для быстрой проверки подключения и статистики команд с телефона.

## 📟 Прошивка Arduino

В репозитории доступна финальная прошивка для основной управляющей платы робота в файле [ardu.ino](ardu.ino).
Arduino решает физические задачи движения и измерений:
* Подсчет тиков левого и правого энкодеров.
* Управление драйвером моторов с П-регулятором скорости для точной обработки заданных линейных и угловых скоростей.
* П-регулятор прямолинейного движения (автоматическая компенсация увода робота в сторону по разнице пройденного пути колес).
* Чтение показаний инфракрасного дальномера (Sharp) и фотодатчиков линии.
* Плавное позиционирование и неблокирующее отключение питания сервопривода оружия.
* Аппаратный таймер безопасности (Watchdog) — автоматический останов при потере команд от управляющего компьютера дольше 0.5 секунд.

## 🔌 Схема подключения (Wiring)

Для успешной работы робота управляющая плата **Arduino** (исполнитель) и модуль **ESP32-C3** (сетевой мост) должны быть соединены между собой и подключены к периферии согласно следующей схеме:

### 1. Межплатное соединение (ESP32-C3 <-> Arduino)
Связь между платами осуществляется через последовательный UART-интерфейс на скорости **38400 бод**:
* **ESP32-C3 TX (Pin 5)** $\rightarrow$ **Arduino RX (Pin A4)**
* **ESP32-C3 RX (Pin 4)** $\rightarrow$ **Arduino TX (Pin A5)**
* **GND** $\rightarrow$ **GND** (общая земля)
* **Питание:** Обе платы должны иметь общую линию питания от аккумулятора (обычно через стабилизатор BEC 5V/3A). ESP32-C3 питается напряжением 3.3 В (или 5 В на платах со встроенным стабилизатором).

### 2. Подключение периферии к Arduino
* **Драйвер моторов (мостовой, например, L298N/TB6612FNG):**
  * Левый мотор (направление): **Pin 4** (`LEFT_DIR_PIN`)
  * Левый мотор (скорость/PWM): **Pin 5** (`LEFT_PWM_PIN`)
  * Правый мотор (скорость/PWM): **Pin 6** (`RIGHT_PWM_PIN`)
  * Правый мотор (направление): **Pin 7** (`RIGHT_DIR_PIN`)
* **Энкодеры обратной связи (моторы):**
  * Левый энкодер канал A: **Pin 2** (внешнее прерывание `0`)
  * Левый энкодер канал B: **Pin 8**
  * Правый энкодер канал A: **Pin 3** (внешнее прерывание `1`)
  * Правый энкодер канал B: **Pin 10**
* **Оружие (активное):**
  * Сервопривод оружия (управление): **Pin 9** (`SERVO_PIN`)
* **Сенсоры:**
  * Датчик линии (левый фототранзистор): **Pin A0** (`LEFT_LINE_PIN`)
  * Датчик линии (правый фототранзистор): **Pin A1** (`RIGHT_LINE_PIN`)
  * Дальномер ИК (Sharp GP2Y0A21YK0F): **Pin A2** (`IR_DISTANCE_PIN`)

## ⚙️ Принципы работы и логика автопилота (Operating Principles)

Система управления роботом построена по распределенной схеме: **Mac/ПК (Компьютерное зрение и высокоуровневый автопилот)** $\rightarrow$ **ESP32-C3 (сетевой TCP/UART шлюз)** $\rightarrow$ **Arduino (низкоуровневый П-контроллер движения и опрос датчиков)**.

### 1. Информационный поток и протокол связи
1. **Камера на Mac/ПК** захватывает изображение поля с частотой ~25 FPS.
2. OpenCV детектирует маркеры ArUco (`DICT_4X4_50`). Направление робота рассчитывается по вектору от центра к передней кромке его ArUco-маркера (`ROBOT_MARKER_ID = 0`).
3. Компьютер вычисляет линейную и угловую скорость и раз в 50 мс отправляет на робота команду движения в формате:
   `VEL <linear_mm_s> <angular_mrad_s>` (например, `VEL 320 1500`).
4. Для управления оружием отправляется команда:
   `SERVO <angle_deg>` (например, `SERVO 160`).
5. Робот в ответ непрерывно шлет строку телеметрии раз в 50 мс:
   `TEL <x> <y> <theta_mrad> <v> <w> <encL> <encR> <lineL> <lineR> <ir_cm> <servo>`
   Компьютер использует показания датчиков линии (`lineL`, `lineR`) для защитных реакций.

### 2. Алгоритмы движения и регуляторы
* **Плавное руление (P-регулятор угла):** Автопилот рассчитывает вектор направления к цели и угол ошибки $\theta_{error}$. Если угол ошибки превышает $45^\circ$, робот разворачивается на месте с максимальной угловой скоростью (`VEL 0 3500`), чтобы быстро навестись на цель. Если угол ошибки меньше $45^\circ$, вступает в силу пропорциональный регулятор угловой скорости: $\omega = K_p \cdot \theta_{error}$, что заставляет робота плавно описывать дугу в движении без остановок.
* **П-регулятор прямолинейного движения (на Arduino):** В прошивке Arduino реализовано поддержание заданной скорости колес и стабилизация курса. При движении прямо Arduino постоянно сравнивает тики левого и правого энкодеров и корректирует PWM моторов, предотвращая увод робота с прямой из-за разности трения или геометрии колес.
* **Watchdog безопасности:** Для исключения аварий (если робот улетит на полной скорости в стену при обрыве связи) в Arduino встроен таймер. Если за последние 500 мс от ПК не поступило ни одной команды `VEL`, робот мгновенно останавливает моторы (`STOP`).

### 3. Автономные режимы боя
* **Режим патрулирования (Waypoint Navigation):** Робот автоматически строит маршрут по ближайшим не посещенным ArUco-маркерам на поле. При входе в радиус точки (`TARGET_TOLERANCE_PX = 70`):
  1. Он останавливается на 0.8 секунд.
  2. Запускается быстрый цикл взмахов активного оружия (сервопривод ходит от $20^\circ$ до $160^\circ$).
  3. Точка заносится в список посещенных, и автопилот переключается на следующую цель.
* **Режим охоты (Hunt Mode):** При обнаружении в кадре вражеского ArUco-маркера из набора `ENEMY_MARKER_IDS` автопилот бросает текущий обход точек, временно меняет цель на вражеский маркер, разгоняется до `ATTACK_SPEED_MM_S = 400` и идет на жесткий таран. В этот момент оружие (сервопривод) начинает качаться с утроенной частотой (`servo_pause_current = 0.5 / 3.0`), нанося непрерывные удары по сопернику.
* **Рефлекс избегания линии (Line Avoidance):** При наезде на белую или черную границу ринга (значения с левого или правого фотодатчиков линии превышают порог `LINE_THRESHOLD = 600`), робот выполняет защитный маневр:
  1. Немедленно останавливает автопилот и сдает назад (`VEL -200 0`) в течение 0.65 сек.
  2. Разворачивается на месте в сторону, противоположную наезду (`VEL 0 3500` или `VEL 0 -3500`) в течение 0.5 сек.
  3. Возвращается к нормальному патрулированию поля.

## 🔌 Настройки автопилота

В файле `arucaupd.py` содержатся основные параметры, которые можно легко изменить:

* `CAMERA_INDEX = 0` — индекс используемой USB-камеры.
* `ROBOT_MARKER_ID = 0` — ID ArUco-маркера на вашем роботе (определяет его положение и направление).
* `ROBOT_ADDRESS = ("192.168.4.1", 8888)` — IP и порт Wi-Fi точки доступа ESP на роботе.
* `ENEMY_MARKER_IDS = {1, 2, 4}` — ID ArUco-маркеров роботов-соперников для автоматического нападения.

## 📦 Быстрый запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/AnubisGmD/Neymark2026_CV_BattleBot.git
   cd Neymark2026_CV_BattleBot
   ```

2. **Установите зависимости:**
   ```bash
   pip install opencv-python numpy flask
   ```

3. **Подключитесь к Wi-Fi сети робота** (например, `NEYMARK_01`).

4. **Запустите программу:**
   ```bash
   python arucaupd.py
   ```

5. **Откройте веб-пульт:**
   В консоли отобразится IP-адрес вашего Mac. Откройте его в браузере телефона или ПК (например, `http://192.168.4.2:5001`).

## 🎮 Управление

### С телефона/ПК (через Web-интерфейс):
* **START (Автопилот):** Запустить автономный обход маркеров.
* **STOP (Останов):** Экстренно остановить робота.
* **HUNT MODE: ON/OFF:** Переключение режима охоты на врагов.
* **Test Servo / Reset Visited:** Тест манипулятора / сброс истории пройденных точек.
* **Show Camera Stream:** Включить живую трансляцию с камеры (рекомендуется выключать при слабом Wi-Fi сигнале ESP).

### С клавиатуры компьютера (в окне OpenCV):
* `SPACE` (Пробел) — Экстренный останов (STOP) и отключение автопилота.
* `R` / `r` — Сброс списка посещенных точек.
* `ESC` — Завершение работы программы.
* `Левый клик мыши` — Ручное указание целевой точки на экране.
